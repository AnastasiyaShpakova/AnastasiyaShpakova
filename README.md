## 🚀 AI и автоматизация: реализованные проекты

### 01. AI-продавец для интернет-магазина

**AI-агент с памятью диалога и интеграциями с CRM и бизнес-сервисами.**

Автоматизирует обработку обращений покупателей: от консультации по товарному каталогу до обновления сделки и создания задачи для дальнейшей обработки заказа.

**Что реализовано:**
- AI-агент на базе DeepSeek с памятью диалога.
- Получение информации о товарах и ценах из Google Sheets.
- Обработка обращений и обновление стадий сделок в amoCRM.
- Формирование счёта в тестовом сценарии.
- Отдельная ветка обработки тестового события оплаты.
- Запись данных в Google Sheets и автоматическое создание карточки Trello.

**Подтверждённый результат:** проверен сквозной сценарий обработки заказа, включая консультацию покупателя, обновление сделки в CRM и создание задачи в Trello.

**Стек:** n8n · DeepSeek · Telegram · amoCRM · Google Sheets · Trello

*Реальный эквайринг не подключён. Подтверждение оплаты проверялось с использованием тестового события.*

### 02. RAG-ассистент для салона красоты

**AI-помощник в Telegram с автоматически обновляемой базой знаний.**

Отвечает на вопросы клиентов об услугах, ценах и режиме работы на основании документов.

**Что реализовано:**
- Получение и обработка PDF-документов из Яндекс.Диска.
- Проверка документов, контроль изменений и версий.
- Разбиение текста на фрагменты и создание embeddings через Ollama.
- Индексация данных и семантический поиск в Qdrant.
- Формирование ответов с помощью LLM.
- Автоматическое обновление базы знаний.
- Проверка результатов загрузки и контроль количества записей.
- Обработка ошибок в сценариях автоматизации.

**Подтверждённый результат:** проверены ответы ассистента по базе знаний, обработка обновлённых документов и поиск информации. Проведена диагностика случаев неполных ответов и ошибок поиска.

**Стек:** n8n · Telegram · Qdrant · Ollama · GigaChat · DeepSeek · Яндекс.Диск

### 03. HR-помощник для подбора кандидатов

**Автоматизация обработки откликов, тестовых заданий и контроля кандидатов.**

**Что реализовано:**
- Получение откликов через Google Sheets.
- Автоматическое создание контактов и сделок в amoCRM.
- Отправка тестовых заданий кандидатам через Gmail.
- Отслеживание ответов на задания.
- Изменение стадий сделок в CRM.
- Уведомления HR в Telegram.
- Ежедневная проверка кандидатов, которые долго находятся на определённом этапе подбора.

**Подтверждённый результат:** протестированы создание сделок, отправка писем, обработка ответов, изменение стадий CRM и уведомления HR, включая контроль кандидатов, находящихся без дальнейшего движения более трёх дней.

**Стек:** n8n · Google Sheets · amoCRM · Gmail · Telegram Bot API

**Все три проекта реализованы самостоятельно и протестированы.** Для них подготовлены PDF-кейсы с архитектурными схемами, реальными интерфейсами и подтверждёнными результатами.
